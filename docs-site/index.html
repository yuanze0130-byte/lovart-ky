统一的 AI API 接入文档

使用一个 OpenAI 兼容地址访问多家 AI 模型。本文档介绍账号、令牌、模型分组、计费、接口格式与服务规则。

API Base URL：https://doodleverse.fun/v1　当前模型：1001

快速开始

  1. 访问 注册页面 创建账号并登录。
  2. 进入“控制台 → API 令牌”，创建并妥善保存令牌。
  3. 在客户端填写 Base URL：https://doodleverse.fun/v1。
  4. 前往 模型广场 选择模型。

创建 API 令牌

令牌只应保存在服务器环境变量或密码管理器中。不要写入前端代码、公开仓库、截图或聊天记录。

# Windows PowerShell
setx DOODLEVERSE_API_KEY "sk-你的令牌"

# macOS / Linux
export DOODLEVERSE_API_KEY="sk-你的令牌"

发送第一条请求

curl https://doodleverse.fun/v1/chat/completions \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"model":"gpt-5.6-luna","messages":[
    {"role":"user","content":"你好，请只回复 OK"}
  ],"max_tokens":10}'

Windows CMD 可将命令写成一行，或使用 Apifox 的“导入 cURL”功能。

用途方法路径

客户端只需替换 Base URL 和 API Key。不同上游模型对工具、图像、视频和音频参数的支持不同，请以模型详情和实际端点能力为准。

模型与端点

模型广场当前启用 1001 个模型，其中按 Token 计费 684 个，按次计费 317 个。另有 46 个包含任意分辨率、时长或输入数量阶梯的参数型模型暂未开放，以避免展示价与实际扣费不一致。

curl https://doodleverse.fun/v1/models \
  -H "Authorization: Bearer YOUR_API_KEY"

错误处理

状态码含义建议
401令牌无效或缺失检查 Authorization
403无权访问检查账号和令牌状态
404路径或模型不存在检查 URL 与模型名
429速率或额度限制降低并发并检查余额
5xx网关或上游异常指数退避，避免立即重复扣费

价格和倍率

按 Token 模型：

费用 = (输入 Token + 输出 Token × 补全倍率)
      × 模型基础倍率 × 分组倍率 ÷ 500,000

按次模型：模型固定价格 × 实际命中分组倍率。图片、音频和视频模型可能按请求、时长、分辨率或其他参数收费。

参数阶梯模型可能产生不同费用。测试时使用最低参数和最小输出，不要直接批量调用。
