# 画布 AI 节点第一阶段交接

日期：2026-09-07。状态：本地实现；未推送、未部署。基于麻衣 V3.5.0 静态代码对比后，依次补齐 AI 文本、AI 表格、独立 Agent 和语音生成的基础闭环。

## 功能与入口

- 左侧「＋」可创建 AI 文本、Agent 节点；画布快捷创建菜单也提供入口。原文字便签及侧栏 Agent 保留。
- AI 文本：独立选择服务器开放模型、填写任务要求，接收上游文字、表格、图片或一段视频，生成结果保存为节点 content，供下游提示词端口读取；结果可手动编辑。
- AI 表格：在原表格中选择模型、填写整理要求。优先读取连线文字，否则读取当前 Markdown；返回结构化列和行，验证通过后才更新表格。原免费格式解析和 CSV 下载保留。新增「输出白底表格图片到画布」。
- Agent 节点：每个节点有自己的角色设定、任务要求、模型与文字输出，可串联多个节点。不是侧栏 Agent 的工具执行代理，不会自动创建或付费运行下游图像、视频节点。
- 语音生成：新增 MiniMax T2A 语音节点，可接收上游文字或直接输入文本，选择模型、音色、语速、音调和 MP3/WAV/FLAC；生成的远程音频会导入云端素材存储后再写入节点，避免上游临时 URL 过期。协议参考 [MiniMax T2A HTTP 文档](https://platform.minimax.io/docs/api-reference/speech-t2a-http)。
- 图片最多 6 张；连接视频时最多 2 张图片加 4 个视频关键帧。视频分析不含音频，也不代表逐帧观看。
- 所有调用需手动触发。AI 文本、Agent 和表格支持取消、超时与失败提示，并防止旧响应覆盖新内容；语音支持失败提示和从任务日志重新运行。失败时保留原结果。
- 语音节点在画布日志中记录排队、运行、成功、素材保存警告和失败；帮助页列出六个语音模型的万字符上游单价及换算积分。服务器未配置共用 Comfly 密钥时，节点明确显示不可用并关闭生成入口。
- 云端项目 JSON 保存新字段；QDMY 导入的 custom-agent 现在映射为独立 Agent，保留输出与提示词。普通 text-node 暂保留普通文字语义；新增 ai-text 可在云端导出/导入往返。并非完整复刻桌面项目执行逻辑。

## 模型配置与计费

复用现有 `XAI_API_KEY` 和 `XAI_BASE_URL`，密钥只在服务端使用。Comfly 语音走 `${XAI_BASE_URL}/minimax/v1/t2a_v2`，无需独立 MiniMax 密钥。已开放页面确认的 `minimax/speech-01-*`、`minimax/speech-02-*` 和 `minimax/speech-2.6-*` 六个官方格式模型；服务端向 MiniMax 协议发送时会移除目录前缀。默认音色仍可通过 `CANVAS_SPEECH_DEFAULT_VOICE_ID` 指定。

语音按实际 Unicode 字符数计费，沿用图片和视频的换算规则：1 个 Comfly 成本单位换算 15 积分，再加 5% 加价并向上取整。Speech 01/02 Turbo 为 ฿2/万字符，其他当前开放型号为 ฿3.5/万字符；例如 10000 字符分别为 32 和 56 积分。前端报价和服务端扣费共用 `speech-pricing.ts`，服务端会校验用户确认的报价。

`CANVAS_TEXT_VISION=true/false` 可以明确指定默认模型是否接收图片。未指定时仅 gpt-4o 系列默认开启。上游权限和实际视觉兼容性仍须验收。

要开放多个模型，在服务器配置 `CANVAS_AI_MODELS_JSON`，例如下面的**结构示例**（模型 ID 和价格需管理员核实，不是可直接使用的真实报价）：

```json
[{"id":"已确认可用的模型ID","label":"显示名称","vision":true,"credits":2,"estimatedCostMicros":8000}]
```

- 每个模型必须明确配置站内积分及保守上游成本估算，最多 30 个模型。格式错误时关闭接口，不静默放开任意模型。
- 不允许浏览器传入任意上游 URL、密钥或绕过白名单。服务端核对显示报价，价格变化时返回 409，要求刷新确认后重试。
- 复用 requireUser 与 runMeteredAiOperation：认证、余额、并发、全局预算与失败退款均沿用现有机制；无需数据库迁移。
- 输出最多 4096 token；截断、空结果、表格结构错误均算失败。上游自动重试关闭，避免一次点击产生隐式重复请求。
- 取消/断网不等于上游未发生费用；若服务端已完成，仍可能计费。不要承诺取消必然退款。

## 已做验证

- `npm run build` 生产构建、TypeScript 检查、全部本轮涉及的源文件 lint 均通过。
- 8 组测试通过：canvas-ai、connections、qdmy、canvas-tools、canvas-render、canvas-shortcuts、ai-tool-guards、public-beta。
- `npm run test:canvas-ai` 使用模拟上游及计费边界：验证鉴权、模型白名单、价格变更、余额不足、图片能力检查、输入上限、表格 JSON、Agent 角色、空/截断/错误输出、错误信息脱敏及限流；没有真实扣费。
- 本地浏览器检查了三个入口、文本编辑、表格解析、白底图片生成，以及刷新后的本地草稿恢复。页面无已捕获的控制台错误。
- 本地未配置 Supabase Auth 环境变量，真实登录、积分数据库与 Comfly 生成未进行端到端验收。模拟测试不等于真实上游可用。

## 发布前验收

1. 在测试环境配置现有认证、上游密钥与已核实的模型/积分；不要把密钥写进文档或前端。
2. 各跑一次文本生成、图片描述、视频关键帧分析、AI 表格及独立 Agent；核对成功扣费、失败退款和余额刷新。
3. 验证「图片 → AI 文本 → 绘画」和「Agent → 表格 → Agent」连线；下游内容更新但不自动发起收费任务。
4. 测试取消、重复点击、删除节点、切换项目、修改上游输入和重载项目。
5. 检查新增节点在已登录用户的云端保存/加载和 QDMY 备份中的状态。
6. 通过验收后再推送并部署；此次没有操作生产环境。

## 后续顺序

基础四项之后：音乐节点与音频时间线 → 视频剪辑时间线 → ComfyUI/RunningHub 通用执行节点。音乐接口和价格尚未核实，当前没有开放音乐付费入口。独立 Agent 的规划、工具分发及自动执行策略仍需后续迭代，不应描述为已经与桌面版完全等价。

## 使用的技能与检查依据

- Next.js 技能：先阅读本仓库安装版本的 Route Handler 指南，再将密钥与调用逻辑留在服务器端。
- Supabase 技能：复用服务端认证和现有原子扣费边界，不修改权限和数据库结构；核对了 [getUser 官方说明](https://supabase.com/docs/reference/javascript/auth-getuser)。变更日志 Markdown 抓取失败，因此没有据此实施任何 Supabase API 升级。
- React Best Practices 技能：共用在途模型目录请求、清理异步请求，检查旧响应覆盖、交互控件和端口布局。
- agent-browser / agent-browser-verify 技能：按页面加载、交互、错误和刷新恢复清单验证；本机没有该 CLI，实际使用可用的 CUA 浏览器工具完成，不宣称 CLI 测试已运行。
